## 🎓 Key Learnings

1. **Async Operations**: Careful state management required for async image generation
2. **Theme Systems**: Dual-mode themes need careful synchronization
3. **Mobile UX**: Touch targets and scrolling need special attention
4. **Performance**: Preventing unnecessary re-renders is critical
5. **Security**: Input validation must be comprehensive from the start
