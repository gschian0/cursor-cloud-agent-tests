# cursor-cloud-agent-tests
Repository for testing cursor cloud agent functionality

## Cursor IDE Setup

This repository is configured to work with [Cursor IDE](https://cursor.sh/), an AI-powered code editor.

### Configuration Files

- **`.cursorrules`**: Contains project-specific rules and guidelines for the Cursor AI assistant
- **`.cursorignore`**: Specifies files and directories that Cursor should ignore when providing context

### Getting Started with Cursor

1. Install [Cursor IDE](https://cursor.sh/)
2. Open this repository in Cursor
3. The AI assistant will automatically use the rules defined in `.cursorrules`
4. Start coding with AI-powered suggestions and assistance

### Features Enabled

- ✅ AI code completion and suggestions
- ✅ Context-aware assistance based on project rules
- ✅ Intelligent file filtering via `.cursorignore`
- ✅ Project-specific coding standards and guidelines
